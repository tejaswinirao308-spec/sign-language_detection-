# Overall Internship Projects Report

## 1. Sign Language Detection

**Objective:** Build a sign-language recognition application with uploaded
image and real-time webcam input.

**Implementation:** The Streamlit system uses MediaPipe hand landmarks and
machine-learning models for selected static signs and known-word video
sequences. It shows a hand box, prediction, confidence, and `Unknown Sign`
when confidence is insufficient. Prediction is restricted to 6:00 PM–10:00 PM
local time.

## 2. Nationality Detection Model

**Objective:** Develop a machine-learning workflow to predict nationality from
the available labelled input data.

**Implementation:** The project includes data preprocessing, model inference,
and a simple interface for presenting the predicted result.

## 3. Data Entry Resume Template

**Objective:** Create a professional resume template for data-entry job
applications.

**Implementation:** The template organises contact information, education,
skills, work experience, and relevant qualifications in a clear format.

## 4. Animal Detection Model

**Objective:** Detect animals in visual input.

**Implementation:** The computer-vision workflow processes images or video
frames and displays detected animal categories with confidence information.

## 5. Emotion Detection Through Voice

**Objective:** Recognise emotion from spoken audio.

**Implementation:** The project extracts relevant audio features and uses a
machine-learning model to classify recognised emotional states, such as happy,
sad, angry, or neutral.

## 6. Car Color Detection

**Objective:** Identify the dominant visible colour of a car.

**Implementation:** The computer-vision pipeline analyses a car image or video
frame and reports the predicted colour.

## Technical Skills Demonstrated

Python, machine learning, computer vision, MediaPipe, OpenCV, Streamlit,
dataset preprocessing, model evaluation, real-time inference, and interface
development.
